# XP4Life Icon Pools

Pool files in this folder feed ICON prompt placeholders such as `{weapon_type}` or `{element}`.

Rules:

- one item per line
- markdown bullets are allowed
- blank lines are ignored
- headings are ignored

Examples:

- `{weapon_type}` -> `weapon_type.md`
- `{element}` -> `element.md`
- `{theme}` -> `theme.md`
- `{tier}` -> `tier.md`

Adding a new placeholder only requires a matching pool file here, for example `creature_type.md` or `aura.md`.
