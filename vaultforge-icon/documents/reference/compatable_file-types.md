# Compatable File Types

Most registered file extensions can be assigned a custom icon by the operating system, launcher, file manager, or an icon-pack tool. The best candidates are file types that are common enough to benefit from visual recognition and stable enough that changing the icon will not confuse users.

## High-Value Targets

- `.txt` - plain text notes
- `.md` - Markdown notes and documentation
- `.pdf` - PDF documents
- `.doc` - legacy Word documents
- `.docx` - Word documents
- `.rtf` - rich text documents
- `.odt` - OpenDocument text documents
- `.xls` - legacy Excel spreadsheets
- `.xlsx` - Excel spreadsheets
- `.csv` - comma-separated data files
- `.ods` - OpenDocument spreadsheets
- `.ppt` - legacy PowerPoint presentations
- `.pptx` - PowerPoint presentations
- `.odp` - OpenDocument presentations

- `.so` - Linux shared libraries

## Folder-Level Targets

- Folders - custom folder icons can often be applied per folder.
- Project folders - useful for distinguishing repos, apps, vaults, and asset packs.
- Shortcut folders - useful for launcher or desktop collections.

## Notes

- File-extension icons are usually changed by extension association, registry entry, desktop environment, or icon-pack tooling.
- Shortcuts can often use custom icons independently of the target file.
- Executables and applications may contain their own embedded icons.
- Some systems cache icons aggressively, so icon changes may require refreshing the icon cache before they appear.
