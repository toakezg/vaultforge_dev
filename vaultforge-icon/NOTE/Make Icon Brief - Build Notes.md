- No-paid-call confirmation: text-only; no image generation, no API call, no
  script creation, no asset movement, and no folder icon application

## Context

`build-notes` holds rough-but-useful workflow material: role definitions, skill
candidates, local tool ideas, seven-cycle thinking, and success measures. In the
icon lane it is not production tooling. It is a thinking shelf: a place where
future workflow shapes can be reviewed before becoming real docs, scripts, or
skills.

The icon should feel like organized working notes with a small spark of future
potential. It should not look like a finished app, an automation engine, or a
live-generation button.

## Concept Directions

1. Notebook with pinned spark
   - A small notebook or stacked pages with one simple pin/star marker.
   - Best for signaling parked ideas that are intentionally saved for later.

2. Workflow cards
   - Three small cards or steps arranged in a tidy sequence, with one card
     slightly highlighted.
   - Best for communicating role/cycle planning without implying automation.

3. Incubation folder
   - A simple folder outline containing a tiny seed or draft mark.
   - Best for showing that the folder stores future candidates, not active
     runtime tools.

## Style Notes

- Keep it quiet, readable, and note-like.
- Prefer paper/card/folder shapes over gear-heavy automation imagery.
- Use restrained accent color only for the "future candidate" marker.
- Avoid magical, over-branded, or high-energy styling.
- The mark should remain understandable as a small folder icon.
