# Icon Proposal Outputs

This folder is approved for future icon proposal documents and generated
proposal images.

Allowed here:

- inbox idea files under `inbox/`
- proposal Markdown files from inspired-agent or `$make-icon` planning runs
- prompt drafts and concept directions for visual review
- proposal metadata that supports review
- generated proposal images from scoped, approved API/paid runs
- run metadata beside generated images

Not approved here without a separate task:

- printing secrets
- adding new cloud auth
- selected or applied icon outputs
- asset moves/deletes
- folder icon application
- final taste decisions

## Suggested Flow

1. Drop rough ideas, folder lists, or style notes into `inbox/`.
2. A proposal run turns those ideas into a named run folder.
3. The run folder contains proposal docs, prompts, images, and metadata.
4. Review chooses directions or asks for another pass.
5. Applying icons remains a separate approved apply-plan task.
