# Proposal Inbox

Drop rough icon-set ideas here as `.md` or `.txt` files.

This inbox is for source direction, not final approval. Future proposal runs may
read these files, turn them into prompt files, generate proposal images, and
record review notes under a named run folder.

## Good Inputs

- folder paths and short descriptions
- subfolder lists with purpose notes
- desired style guide or color semantics
- whether icons should feel unique, shared as a set, or mixed
- notes about what should not appear in the icon

## Example

```md
# Media Folder Icon Set

Style source: `f:\media\icons\my_icons\style-guide.txt`

Set style:
- unified folder-icon family
- simple centered symbolic mark
- no text or letters
- transparent background

Targets:

## F:\media\videos
- Purpose: video and active playback storage
- Style: orange/gold
- Ideas: play triangle, timeline, active glow

## F:\media\images
- Purpose: images and gallery work
- Style: green
- Ideas: framed image, gallery stack, small sparkle
```

## Boundaries

Do not put secrets, API keys, private client details, or final apply approval in
this inbox.

Applying icons to folders remains a separate apply-plan/apply task.
