# Media Style Guide Note

Source: `f:\media\icons\my_icons\style-guide.txt`

Status: reference style input for future proposal runs.

## Color Semantics

- Orange / Gold: video / active playback
- Blue / Cyan: mixed media / general media
- Green: images / gallery
- Purple: audio / sound
- White / Neutral: raw / unassigned

## Use

Future icon-set proposal runs may use these color meanings when a proposal asks
for media-folder icons or a media-style icon family.

This note does not approve folder-icon application by itself.
