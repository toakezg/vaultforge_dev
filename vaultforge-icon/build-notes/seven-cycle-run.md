# Seven-Cycle Run Shape

```text7A 
Cycle 1: Coordinator creates build brief and budget.
Cycle 2: Builder does first small implementation.
Cycle 3: Reviewer verifies and catches drift.
Cycle 4: Builder fixes first blocker or improves the working path.
Cycle 5: Inspiration Scout proposes next directions using fixed areas.
Cycle 6: Coordinator chooses one next/park/reject path and Recorder updates docs.
Cycle 7: Final review, budget/taste/load report, next resume prompt.
