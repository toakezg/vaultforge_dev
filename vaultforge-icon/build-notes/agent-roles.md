# Agent Roles

```text
Coordinator
Owns scope, cycle count, routing, stop rules, approvals, and next-cycle choice.

Builder
Does the concrete implementation work.

Reviewer
Checks the work for bugs, scope drift, missing verification, and bad ownership.

Recorder
Updates SIGN_UP.md, TASKS.md, CHANGELOG.md, handoff, reports, and resume prompt.

Inspiration Scout
Looks at what landed and proposes future directions, not random work.

Feasibility Reviewer
Assesses creative proposals against foundation, risk, cost, dependencies, and section ownership.

Wildcard / Icon Muse
Optional later creative role that suggests one visual/icon identity prompt inspired by the completed work.
```
