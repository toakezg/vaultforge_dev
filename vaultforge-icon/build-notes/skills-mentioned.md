Creative icon skill. Turns folder/lane/client/task purpose into icon concepts or generated assets.

Practical icon application skill. Applies existing icons safely, preferably through dry-run batch plans.

Routes work to the right VaultForge lane using THREAD_MAP.md and section docs.

Creates the short cycle brief: target, files, success check, stop/ask condition.

$review-handoff-writer
Turns completed/reviewed work into SIGN_UP/TASKS/CHANGELOG/handoff updates.

Runs or records dry-run/test results and saves the verified state clearly.

$inspiration-scout
Could become its own skill later: proposes bounded ideas using 5 direction areas.
