# Good Starting Set

For the first serious 7-cycle run, do not include everything.

Start with this:

```text
Roles:
- Coordinator
- Builder
- Reviewer
- Recorder
- Inspiration Scout

Skills/processes:
- build brief
- style/taste checkpoint
- smoke-test recorder
- review/handoff writer
- bounded inspiration proposal

Tools:
- no make/apply icon yet unless the run is specifically about designing them
- dry-run/test commands only
```
