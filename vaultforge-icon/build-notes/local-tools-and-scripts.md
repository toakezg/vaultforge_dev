# Local Tools And Scripts

```text
make_icon.py
Script/tool behind $make-icon. Handles prompt/assets/metadata, not project judgment.

run_make_icon.bat
Windows launcher for make_icon.py.

apply_icon.py
Script/tool behind $apply-icon. Plans, dry-runs, and applies icon placement.

run_apply_icon.bat
Windows launcher for apply_icon.py.

apply_icon.py plan
Creates a batch apply plan.

apply_icon.py dry-run
Shows exact proposed physical changes without applying.

apply_icon.py apply --approved-only
Applies only a reviewed/approved batch.

icon-apply-plan.json / .md
Reviewable batch plan for folder icon applications.

icon-apply-report.md
Report after apply, listing what changed.
```
