# VaultForge Icons - Price Guide

Draft only. Adjust after testing real jobs.

## Starter Logo/Icon Concepts

Price range:

```text
$20-$40
```

Includes:

- 5 generated directions
- 1 style/profile
- 1 selected final image
- light cleanup/selection help

## Standard Option Pack

Price range:

```text
$50-$80
```

Includes:

- 10-15 generated directions
- 2-3 style/profile directions
- 3 selected final images
- simple social/profile-ready export set

## Premium Mini Brand Pack

Price range:

```text
$100+
```

Includes:

- larger generation batch
- final selected logo/icon
- color variations
- simple social media image set
- delivery folder with organized files

## Pricing Rule

Keep the first tests low-pressure.

The first goal is validation:

- Did anyone message?
- Did anyone pay even a small amount?
- Which styles did people like?
- How much time did delivery really take?
