# Examples

These examples show how `project-pack` can look once it has been customized
into a real project shape.

Use them when you want a stronger starting point than the raw templates.

## Available examples

- `root-coordinator/` - a sample project root using the root-and-workstreams
  model
- `shared-platform-workstream/` - a shared foundation lane
- `delivery-lane-workstream/` - a workflow and output lane
- `external-runtime-workstream/` - a coordination layer above an external tool
  or runtime
- `setup-tooling-workstream/` - a bootstrap and tooling lane

Copy the closest example, then replace names and boundaries with the real ones
for the target project.
