# Example Project

`Example Project` uses a root-and-workstreams model.

Root is the coordination layer for:

- architecture
- planning
- work routing
- handoffs
- project-level docs

Active workstreams in this example are:

- `platform-core`
- `delivery-lane`
- `creative-runtime`
- `project-setup`

Use this example when you want to scaffold a full root layer before
customizing the names and boundaries.
