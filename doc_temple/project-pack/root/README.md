# {project_name}

`{project_name}` uses a root-and-workstreams model.

Root is the coordination layer for:

- architecture
- planning
- handoffs
- work routing
- project-level documentation

Active workstreams are focused ownership areas.

Use this root folder to keep the project legible as it grows:

- `CODEX_START.md` boots new threads
- `SYSTEM.md` defines the operating model
- `THREAD_MAP.md` routes work
- `PLAN.md` holds direction
- `TASKS.md` holds actionable project-level work
- `CHANGELOG.md` records notable project-level changes

This root template is intentionally lightweight. Deep local execution belongs
in active workstream folders.
