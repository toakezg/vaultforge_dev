# {project_name}

`{project_name}` uses a root-and-sections model.

Root is the coordinator layer for:

- architecture
- planning
- handoffs
- section routing
- coordination-level documentation

Promoted sections are focused worker bases.

Use this root folder to keep the project legible as it grows:

- `CODEX_START.md` boots new threads
- `SYSTEM.md` defines the operating model
- `THREAD_MAP.md` routes work
- `PLAN.md` holds direction
- `TASKS.md` holds actionable work
- `CHANGELOG.md` records coordination-level changes

This root template is intentionally lightweight. Section-specific execution
belongs in promoted section folders.
