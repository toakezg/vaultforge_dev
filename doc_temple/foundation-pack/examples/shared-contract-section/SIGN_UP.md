# Shared Core Sign Up

New shared-core threads should add a short entry here before or after their
first meaningful change.

Use this shape:

```text
## YYYY-MM-DD - thread label

- Role:
- Scope:
- Read:
- Changed:
- Handoff:
```

## YYYY-MM-DD - section setup

- Role: initial shared-core section setup
- Scope: section docs and startup requirements
- Read: root startup docs and local section docs
- Changed: created the example shared-contract pack
- Handoff: next thread should refine compatibility and validation boundaries
