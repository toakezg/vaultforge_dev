# Project Init Sign Up

New project-init threads should add a short entry here before or after their
first meaningful change.

Use this shape:

```text
## YYYY-MM-DD - thread label

- Role:
- Scope:
- Read:
- Changed:
- Handoff:
```

## YYYY-MM-DD - section setup

- Role: initial setup-tooling section setup
- Scope: section docs, setup boundaries, and first-run guidance
- Read: root startup docs and local section docs
- Changed: created the example setup-tooling pack
- Handoff: next thread should refine install and troubleshooting guidance
