# Example Project

`Example Project` uses a root-and-sections model.

Root is the coordinator layer for:

- architecture
- planning
- section routing
- handoffs
- coordination-level docs

Promoted sections in this example are:

- `shared-core`
- `delivery-lane`
- `creative-bridge`
- `project-init`

Use this example when you want to scaffold a full root layer before customizing
the names and boundaries.
