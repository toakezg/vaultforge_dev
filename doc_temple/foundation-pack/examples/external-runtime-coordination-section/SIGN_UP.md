# Creative Bridge Sign Up

New creative-bridge threads should add a short entry here before or after their
first meaningful change.

Use this shape:

```text
## YYYY-MM-DD - thread label

- Role:
- Scope:
- Read:
- Changed:
- Handoff:
```

## YYYY-MM-DD - section setup

- Role: initial external-runtime coordination setup
- Scope: section docs, bridge warnings, and migration boundaries
- Read: root startup docs and local section docs
- Changed: created the example external-runtime coordination pack
- Handoff: next thread should refine bridge inventory and migration guidance
