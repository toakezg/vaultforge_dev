# Foundation Pack Examples

These folders are pre-assembled example packs built from the base templates and
profile overlays.

Use them when you want a faster starting point than building from
`section-core/` by hand.

## Available examples

### `root-coordinator`

A filled root example showing:

- a coordinator layer
- a thread map
- example promoted sections

### `shared-contract-section`

An engine-like example for shared runtime, API, metadata, or contract sections.

### `operator-lane-section`

A business-like example for wrappers, prompt banks, outputs, review surfaces,
and delivery workflows.

### `external-runtime-coordination-section`

An art-like example for coordination layers that sit above an external runtime.

### `setup-tooling-section`

An init-like example for bootstrap scripts, installers, environment setup, and
tooling lanes.

## How to use an example

1. Copy the example folder contents into the target location.
2. Rename the section to match the real lane.
3. Replace example wording with project-specific wording.
4. Update root `THREAD_MAP.md` to include the real section.

Examples are meant to accelerate the first draft, not replace local thinking.
