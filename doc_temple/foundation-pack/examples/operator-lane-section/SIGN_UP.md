# Delivery Lane Sign Up

New delivery-lane threads should add a short entry here before or after their
first meaningful change.

Use this shape:

```text
## YYYY-MM-DD - thread label

- Role:
- Scope:
- Read:
- Changed:
- Handoff:
```

## YYYY-MM-DD - section setup

- Role: initial operator-lane section setup
- Scope: section docs and workflow boundaries
- Read: root startup docs and local section docs
- Changed: created the example operator-lane pack
- Handoff: next thread should refine wrapper, routing, and review rules
