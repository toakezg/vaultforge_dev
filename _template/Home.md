# Home

This vault starts with the core Obsidian setup plus an optional XP4Life Icons Part A pipeline.

## Optional Starting Points

- `NOTE/Icons - part A.md`
- `NOTE/Icons - part A - quick use guide.md`
- `NOTE/How to - Create XP4Life Icon set (obsidian).md`
- `NOTE/Icons - part A - output review.md`
- `run-icons-part-a.bat`

## Output Location

If you use the icon pipeline, generated files land under:

```text
ICON\XP4Life\part-a\generated\
```

Approved reusable icons should be copied into:

```text
ICON\XP4Life\part-a\selected\
```
